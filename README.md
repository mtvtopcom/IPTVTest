# IPTV 直播源测试（IPTVTest）

一款 macOS 桌面版 IPTV 直播源自动更新工具，参考 [Guovin/iptv-api](https://github.com/Guovin/iptv-api) 的思路做了简化重写：
采集本地文件源、订阅源、粘贴的输入源 → 解析出频道条目 → HTTP 探测 + ffmpeg（ffprobe）深度校验 → 输出可直接播放的 M3U / TXT / JSON。

纯 Python 3 标准库（tkinter GUI），无需安装第三方依赖；内置静态 ffmpeg/ffprobe 二进制用于深度校验。

## 功能特性

- **数据源管理**：文件源（M3U/TXT）、订阅源（自动展开子订阅）、输入源（粘贴文本），实时显示每个源解析出的条数
- **单次运行**：
  - **排重更新**：只检测「所有数据源管理」中没有的地址，已测过的自动跳过，速度快
  - **全量更新**：对所有源重新完整检测一遍（带二次确认）
  - **不可用分析**：检测过程中按大分类（HTTP 错误 / 连接超时 / 连接失败 / 格式无效 / 规则过滤 / 深度校验失败…）实时统计失败构成
- **验证结果**：当前一次运行中验证成功的源，支持搜索（频道/分组/地址/分辨率/深度校验/来源）、全列正倒序、全选/播放/复制/批量重测/删除、按搜索结果导出 M3U / TXT / CSV
- **所有数据源管理**：安装以来导入过的全部数据（按 URL 归并，同址只存一条），分「验证成功 / 验证失败」两个子页，累计成功次数、失败次数、最新状态、最近验证时间，重测后自动累加，永不清空
- **输出**：`output/result.m3u`、`result.txt`、`result.json`；内置本地 API（`/m3u` `/txt` `/json` `/api/status`）可供播放器或其它设备直接订阅
- **深度校验**：HTTP 流探测之外，可用 ffprobe 抓取分片解析真实分辨率、编码等信息

## 目录结构

```
iptv-tool/
├── gui.py          # tkinter 图形界面入口
├── cli.py          # 命令行入口（无界面运行）
├── core/           # 采集 / 解析 / 校验 / 引擎 / 输出 / 本地 API
├── selftest.py     # 自测脚本（python3 selftest.py [--deep]）
├── build_app.sh    # 打包 macOS .app 脚本
├── assets/         # 应用图标
└── bin/            # 静态 ffmpeg / ffprobe（打包时注入，不入库）
```

数据与输出目录在 `~/IPTV直播源测试/`（可用环境变量 `IPTV_HOME` 重定向）：`config/` 配置、`output/` 结果、`logs/` 日志。

## 快速开始

```bash
# 源码直接运行（macOS，需要 tkinter，可用 python.org 官方安装包）
python3 gui.py

# 命令行
python3 cli.py

# 自测
python3 selftest.py --deep

# 打包成 .app
./build_app.sh
```

或直接到 [Releases 页面](https://github.com/mtvtopcom/IPTVTest/releases/latest) 下载 `IPTVTest-macOS-*.zip`，解压得到 `IPTV直播源测试.app`（内置 ffmpeg，无需 Python 环境）。
